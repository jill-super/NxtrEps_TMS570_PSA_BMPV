# RTE & Generated Configuration

:::note[Origin: Vector-provided, customised]
Based on Vector MICROSAR artefacts (RTE/IL/GenData generation) with project-specific customisation (PSA serial communication, calibration data, configured RTE). Regenerate — do not hand-edit generated files.
:::

## Purpose

Machine-generated integration artefacts that bind the application SW-Cs to the
BSW: RTE contract/schedule files, BSW post-build configuration and OS
configuration. Typical generator markers found in this repository:

- `Generator: MICROSAR RTE Generator` headers in `Ap_*/Sa_*` template files,
- DaVinci component descriptions (`*.dcf`, `*.arxml`) in each module's `autosar/` folder,
- generation templates (`generate/*.tt`) plus `*_Generate.bat` scripts per module,
- Vector make fragments (`mak/Rte_*.mak`, `mak/Dem_*.mak`).

## Locations

- `PSA_BMPV_EPS_TMS570/SwProject/Source/GenData/` — application/RTE configuration
  (per-SW-C `*_Cfg.h/.c`, e.g. `Ap_Assist_Cfg.h`).
- `PSA_BMPV_EPS_TMS570/SwProject/Source/GenDataRte/` — RTE generator output and
  make fragments (`mak/Rte_cfg.mak`, `Rte_rules.mak`, …).
- `PSA_BMPV_EPS_TMS570/SwProject/Source/GenDataOS/` — OS configuration.
- `<module>/generate/` — per-module generator inputs (`.tt` templates, `.bat` launchers,
  `*_bswmd.arxml`), documented on each module page.

## Workflow

1. Model the component in DaVinci Developer / configure the stack in DaVinci Configurator (GENy for the IL).
2. Run the module `generate/*_Generate.bat` (or the central generation step).
3. Rebuild the ECU image; never hand-edit files under `GenData*` — changes are lost on regeneration.

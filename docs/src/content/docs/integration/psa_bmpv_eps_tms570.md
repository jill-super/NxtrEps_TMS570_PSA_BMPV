# PSA_BMPV_EPS_TMS570

:::tip[Origin: Custom (in-house)]
Developed in-house (Nexteer EPS application team). RTE/scaffolding files inside may be auto-generated by the Vector MICROSAR RTE Generator from the DaVinci component model — see the RTE & GenData page.
:::

## Purpose

ECU project integration for the PSA BMPV EPS on TMS570: BSW sources, RTE/GenData configuration and build artefacts.

## Structure

- `SwProject/CDDInterface`, `SrlComDriver`, `SrlComInput`, `SrlComOutput`, `CustBattDiag`, `DemIf`, `DfltConfigData`, `DiagSvc`, `FaultLog`, `IoHwAbstractionUsr`, `VehPwrMd`, `CMS_PSA`, `ChkPt`, `NtWrap`, `Header` — project-level SW-Cs/CDDs, each with its own documentation page in this site.
- `SwProject/Source/` — integrated ECU sources: `BSW/` (Vector stack), `CDD/` (`BasicSysSrvc`, `MtrCtrl`), `GenData` / `GenDataRte` / `GenDataOS`, `IoHwAb.c`, `SchM.c`, application callouts and the CCS project (`.ccsproject`, `Linker.cmd`).
- `SwProject/Tools/` — host-side tooling (QAC, Polyspace, metrics, CCT, patch tooling).
- `HLDD/` — Vector high-level design references (see [HLDD page](../hldd/)).

## Build

The ECU image is built with TI Code Composer Studio (see `.ccsproject`) and the Vector/GENy make fragments under `Source/GenDataRte/mak/`. Details: [Build system](../../general/build-system/).
